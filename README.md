# 一水千田｜資料驅動網站＋後台管理系統

前台（首頁、小遊戲、桌遊介紹）沒有寫死的內容，全部讀 `data.json`。後台 `admin.html` 用表單修改內容，按「發布」寫回 GitHub，不用碰程式碼。

---

## 1. 架構與資料流

```
yq-cms/
├─ index.html        前台（空殼，內容由 js/app.js 產生）
├─ admin.html        後台管理系統
├─ data.json         ★ 全站唯一的內容來源
├─ css/style.css     前台樣式；最上面 :root 是全站色票
├─ css/admin.css     後台樣式
├─ js/store.js       前後台共用：讀資料、草稿、驗證、雷達圖
├─ js/app.js         前台：把資料畫成頁面
├─ js/games.js       兩個小遊戲（快問快答、埤塘管理員）
├─ js/admin.js       後台：表單、清單增刪改、圖片上傳、GitHub 發布
└─ images/uploads/   後台上傳的圖片
```

```
              ┌────────────── 後台 admin.html ──────────────┐
  修改欄位 →  │ 草稿（存在這個瀏覽器）                        │
              │   ├─ 按「預覽」→ index.html?preview=1 讀草稿，後台一改就跟著變
              │   └─ 按「發布」→ 檢查內容 → 上傳圖片 → 寫入 GitHub 的 data.json
              └──────────────────────────────────────────────┘
                                         ↓ 約 1～2 分鐘
  訪客打開 index.html  →  讀 data.json  →  畫出首頁、小遊戲、桌遊介紹
```

- **草稿**只有你自己看得到；**發布**之後所有訪客才看得到。
- 發布前會自動檢查（例如題目沒寫、正確答案指到空白選項、人數最少大於最多），有問題會跳到那個欄位。
- 發布時如果線上內容被其他組員改過，會先問你要不要蓋掉。

### data.json 的結構

| 區塊 | 內容 | 後台模組 |
|---|---|---|
| `site` | 網站名稱、公告、導覽列、首頁主視覺、聯絡資訊、頁尾 | A 網站內容 |
| `home.bento` | 首頁重點卡片（大小、標題、數字、連結、圖片） | A |
| `home.timeline` | 大事記 | A |
| `games.quiz` | 快問快答：規則、題數、秒數、計分、難度、稱號、題庫 | B 小遊戲 |
| `games.pond` | 埤塘管理員：規則、季數、計分、各難度的容量／需水量／進水量 | B |
| `boardgames` | 雷達圖項目；每款桌遊的名稱、標籤、人數、時間、評分、陷阱、心法、圖片 | C 桌遊百科 |
| `meta.updatedAt` | 上次發布時間（用來偵測別人是否改過） | 自動 |

## 2. 第一次上線（約 15 分鐘）

1. **建立儲存庫**：GitHub 新增一個**公開**儲存庫（例如 `yishui-web`），把這個資料夾裡的所有檔案上傳到最外層。
2. **開啟 Pages**：Settings → Pages → Source 選 Deploy from a branch → Branch 選 `main`、`/ (root)` → Save。約 1～2 分鐘後網址是 `https://你的帳號.github.io/yishui-web/`。
3. **申請權杖**（給後台發布用）：GitHub 右上頭像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。
   - Repository access：Only select repositories → 只選這個儲存庫
   - Permissions → Repository permissions → **Contents：Read and write**
   - 產生後把權杖複製起來（只會顯示一次）。
4. **設定後台**：打開 `https://你的帳號.github.io/yishui-web/admin.html` → 左邊「發布設定」→ 帳號和儲存庫會自動帶入，貼上權杖 → 按「測試連線」看到「連線成功」就完成了。

## 3. 平常怎麼改內容

1. 打開 `…/admin.html`（手機也可以）。
2. 左邊選模組：**A 網站內容**、**B 小遊戲**、**C 桌遊百科**。
3. 直接改欄位。清單（導覽列、卡片、題庫、桌遊）可以按「＋新增」，每一項右邊有 ↑ ↓ 排序和 ✕ 刪除。
4. 圖片按「上傳圖片」選檔，會自動縮小。
5. 按右上「**預覽**」看結果；滿意後按「**發布**」。網站 1～2 分鐘後更新。

常用操作：

| 想做的事 | 去哪裡 |
|---|---|
| 換公告、關掉公告 | A → 公告 |
| 改首頁大標、按鈕 | A → 首頁主視覺 |
| 加一張重點卡片 | A → 首頁重點卡片 → ＋新增卡片 |
| 加題目、改答案 | B → 快問快答：題庫 |
| 調整遊戲難度 | B → 難度（時間倍率、容量、需水量…） |
| 暫時下架一個遊戲 | B → 取消勾選「在網站上顯示這個遊戲」 |
| 新增一款桌遊、改雷達圖 | C → 桌遊清單 |
| 備份、還原 | 發布設定 → 匯出／匯入 data.json、捨棄草稿 |

## 4. 在自己電腦上測試

用 VS Code 打開資料夾 → 安裝 **Live Server** → 右下角 Go Live。直接點兩下打開 `index.html` 會讀不到 `data.json`（瀏覽器的限制）。
本機沒有發布到 GitHub 也能用：改完按「匯出 data.json」，把檔案蓋掉資料夾裡的 `data.json` 即可。

## 5. 要知道的限制

- **後台網址是公開的**，但沒有權杖就無法發布，所以別人打開也改不了網站。權杖等於這個儲存庫的寫入鑰匙：不要貼到群組或截圖，公用電腦不要勾「記住權杖」。組員各自申請自己的權杖（要先被加為儲存庫的協作者）。
- 草稿存在瀏覽器裡：換電腦或清除瀏覽資料，還沒發布的修改就不見了。大改之前先匯出備份。
- 兩個人同時改：後發布的人會收到提醒；選「仍要發布」會蓋掉前一個人的修改。
- 發布功能是用模擬的 GitHub 測試過的，**還沒對真正的儲存庫發布過**；第一次發布若出現錯誤訊息，照訊息檢查權杖權限與儲存庫名稱。
- 桌遊內容、提示文字、遊戲數值都是示意，規則定案後在後台改。歷史數字沿用原網站的資料，仍待對照原始文獻。
- 這是全新的網站，原本 yishui-site 的互動地圖、大圳故事、3D 模型沒有搬過來；需要的話可以在導覽列加連結連回去。
